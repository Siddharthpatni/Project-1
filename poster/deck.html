01
Problem & Motivation
Every new data source needs a scraper
built from scratch.
That is slow, costly, and hard to scale. As the number of portals grows, the engineering effort itself becomes the bottleneck.
  • Hundreds of portals — DTVP, NetServer, Cosinex, RIB, Subreport… each with its own layout & login walls.
  • Manual work doesn't scale — one custom scraper per source, maintained by hand.
  • Portals change — scrapers silently break and tenders are missed.
vergabepilot.AI
02
The Idea
What if the system writes, tests and fixes
its own scraper — for any portal?
An LLM generates a Python scraper per domain inside a closed generate → validate → execute → evaluate loop, with a visual computer-use agent as a fallback and a cost-aware cascade that reuses cached scrapers first.
03
System Architecture
One pipeline, three extraction phases
Next.js UI› FastAPI · /api/jobs› Celery worker pool· Redis
↳ Phase 1 · Scraper feedback loop Phase 2 · CUA agent Phase 3 · Cost-aware cascade
↳ MinIO (S3) — documents Postgres — metadata
A job is enqueued from the UI, fanned out across parallel workers, and routed through the phases; documents land in object storage with metadata in Postgres.

04
Phase 1 · The core innovation
A scraper that repairs itself
Generator
Takes a URL and writes a Python scraper for that domain via LLM.
Validator
Checks code safety with AST analysis before anything runs.
Executor
Runs it in a sandboxed subprocess with memory & timeout limits.
Evaluator
Compares results to expected output and flags discrepancies.
Generate → Validate → Execute → Evaluate   ✓ save  ·  ✗ feedback → regenerate ↺
vergabepilot.AI
05
Phase 2 & 3 · Fallback and routing
When code isn't enough — and paying only when needed

Phase 2 — CUA Agent

Visual fallback
  • A computer-use agent navigates the portal like a human with Playwright.
  • Handles dynamic pages where a generated scraper can't reach the documents.
  • Used as a fallback, not a default — it is the most expensive path.

Phase 3 — Cost-Aware Cascade

Cheapest viable strategy first
Cached scraper ~free
Deterministic template (DTVP/ZIP) cheap
LLM-generated (Phase-1 loop) AI
CUA agent AI
Store → MinIO + Postgres save
